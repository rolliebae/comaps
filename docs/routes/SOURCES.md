# Источники АЗС и уровни доверия

## Приоритет

### 1. OSM / CoMaps — геометрия и навигация

CoMaps использует OSM для POI и дорожной сети. Для топливных POI ожидаются:

- `amenity=fuel`
- `brand=Роснефть` / Rosneft
- `fuel:octane_95=yes` — если марка топлива размечена

OSM object id не фиксируется в маршруте. Связь делается по координате с радиусом 750 м и семантике fuel station.

### 2. Роснефть — идентичность АЗС

Публичный поиск: <https://rosneft-azs.ru/stations>

**424 км:** координата `52.376106, 38.894249` соответствует адресу `424-й км, зд. 94а`. В публичных материалах Роснефти этот объект указан как **АЗК №281**.

Источник: <https://rosneft-azs.ru/upload/site1/document_news/2025/Spisok_obnovlennykh_AZK2.pdf>

**108 км:** публичные материалы Роснефти прямо сопоставляют 108 км Москва—Ростов—Дон, левую сторону, с кодом **MJ247**.

Источник: <https://rosneft-azs.ru/news/169599>

**711 км:** точные координаты `50.174728, 40.407089` и адрес Верхний Мамон / ул. Дорожная, 30 сопоставлены с номером **50** в партнёрском координатном каталоге. Свежий официальный публичный идентификатор Роснефти для этой точки в ходе проверки не был найден, поэтому в данных стоит `official_identity_verified=false`.

Источник корреляции: <https://lk.ariscard.com/download/rus_2.pdf>

### 3. ГдеБЕНЗ — live-статус

ГдеБЕНЗ используется только как внешний браузерный слой для свежих отметок водителей:

- М-4: <https://gdebenz.ru/trassa/m4-don>
- АИ-95: <https://gdebenz.ru/fuel/ai-95>
- Ступино: <https://gdebenz.ru/gde-zapravitsya/stupino>
- резерв сети: <https://www.gdebenz.org/brand/rosneft>

В приложении нет фонового HTTP-доступа, scraping, parsing, caching или mirror данных ГдеБЕНЗ.

## Что считать конфликтом

Если OSM, Роснефть и ГдеБЕНЗ расходятся:

- координаты/дороги — использовать OSM/CoMaps;
- идентификатор и справочный объект сети — использовать официальную Роснефть;
- текущий водительский статус — показывать только как краудсорсинговый сигнал ГдеБЕНЗ с оговоркой о свежести;
- при отсутствии свежего подтверждения не делать вывод «АИ-95 точно есть».
