## Модель источников

Маршрут не пытается получить всё из одного сервиса:

1. **OpenStreetMap / CoMaps** — геометрия, POI и дорожная маршрутизация.
2. **Роснефть** — идентичность конкретной АЗС и справочная информация о сети. Основной публичный каталог: <https://rosneft-azs.ru/stations>.
3. **ГдеБЕНЗ** — только краудсорсинговый live-статус перед заездом. CoMaps открывает публичную страницу в браузере и не запрашивает, не парсит, не кэширует и не зеркалирует данные сервиса.

OSM object id намеренно не хардкодится. Node/way может быть перемаплен или заменён редакторами OSM; для этого маленького маршрута более устойчивой связкой является координата + `amenity=fuel`/брендовая семантика CoMaps с радиусом 750 м.

## АИ-95

`АИ-95` — обязательная политика этого маршрута. В OSM ожидаемый тег — `fuel:octane_95=yes`, но его отсутствие не считается доказательством отсутствия топлива: OSM может отставать. Для справочного ассортимента первичнее публичный каталог Роснефти; фактическое наличие «прямо сейчас» проверяется отдельно на ГдеБЕНЗ.

Fallback Android:

1. основной route/local экран ГдеБЕНЗ;
2. страница АИ-95 ГдеБЕНЗ;
3. резервный публичный домен ГдеБЕНЗ;
4. официальный публичный каталог АЗС Роснефти;
5. системный `geo:` intent на точные координаты;
6. понятная ошибка вместо падения.

## Как использовать в CoMaps

Импортируйте GPX и используйте пять точек как старт, три остановки и финиш. CoMaps сам рассчитывает автомобильный путь по локальным картам. Перед каждой топливной остановкой открывайте кнопку ГдеБЕНЗ и проверяйте **эту Роснефть + АИ-95 + свежесть отметки**.

Важно: никакой источник не трактуется как гарантия наличия топлива в будущем. Маршрут хранит план и источники проверки, а не обещание, что АИ-95 будет на колонке в момент прибытия.
