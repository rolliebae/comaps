## Как использовать в CoMaps

CoMaps умеет импортировать GPX. После импорта файл создаёт именованные точки и маршрутную линию. Для реальной автомобильной навигации используйте эти точки как старт, промежуточные остановки и финиш, чтобы CoMaps самостоятельно рассчитал дорожный маршрут по актуальным офлайн-картам.

## Интеграция ГдеБЕНЗ

Интеграция остаётся **browser-only**: CoMaps не запрашивает, не парсит, не скрейпит, не кэширует и не зеркалирует статусы ГдеБЕНЗ.

Публичный интерфейс ГдеБЕНЗ поддерживает выбор конкретной АЗС на карте, фильтр марки топлива **АИ-95**, страницы трасс/городов и построение маршрута. В ходе проверки не использовался и не предполагается недокументированный постоянный permalink отдельной карточки АЗС. Поэтому идентичность трёх запланированных АЗС хранится в CoMaps по координатам, а кнопка открывает наиболее узкий подтверждённый публичный экран ГдеБЕНЗ:

| Точка CoMaps | Основной экран ГдеБЕНЗ | Что проверить |
|---|---|---|
| Роснефть М-4 711 км | <https://gdebenz.ru/trassa/m4-don> | эта Роснефть + АИ-95 + свежесть отметки |
| Роснефть М-4 424 км | <https://gdebenz.ru/trassa/m4-don> | эта Роснефть + АИ-95 + свежесть отметки |
| Роснефть М-4 108 км | <https://gdebenz.ru/gde-zapravitsya/stupino> | эта Роснефть + АИ-95 + свежесть отметки |

Страница АИ-95: <https://gdebenz.ru/fuel/ai-95>.

### Безопасный fallback

Android-кнопка **«Проверить эту Роснефть · АИ-95 на ГдеБЕНЗ»** действует так:

1. для точки 711/424 км открывает официальный экран М-4, для 108 км — официальный экран Ступино;
2. если Android не может открыть основной web-intent, пробует официальный запасной адрес сети: <https://www.gdebenz.org/brand/rosneft>;
3. если браузера/обработчика URL нет, пробует системный `geo:`-intent с точными координатами выбранной АЗС;
4. если нет и картографического приложения, показывает ошибку вместо падения приложения.

Проверить сетевой сбой сайта после передачи URL браузеру CoMaps намеренно не пытается: для этого потребовался бы отдельный сетевой запрос. Запасной официальный домен указан в GPX/JSON и документации, чтобы пользователь мог открыть его вручную при недоступности основного домена.

Важно: данные ГдеБЕНЗ краудсорсинговые и могут меняться в пути. GPX хранит план остановок и требование **Роснефть + АИ-95**, а не подтверждение фактического наличия топлива.
