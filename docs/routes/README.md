## Как использовать в CoMaps

CoMaps умеет импортировать GPX. После импорта файл создаёт именованные точки и маршрутную линию. Для реальной автомобильной навигации используйте эти точки как старт, промежуточные остановки и финиш, чтобы CoMaps самостоятельно рассчитал дорожный маршрут по актуальным офлайн-картам.
