## Как использовать в CoMaps

CoMaps умеет импортировать GPX. После импорта файл создаёт именованные точки и маршрутную линию. Для реальной автомобильной навигации используйте эти точки как старт, промежуточные остановки и финиш, чтобы CoMaps самостоятельно рассчитал дорожный маршрут по актуальным офлайн-картам.

## Интеграция ГдеБЕНЗ

Для трёх топливных остановок маршрут связан с официальным сайтом [ГдеБЕНЗ](https://gdebenz.ru/):

- сеть: **Роснефть**;
- топливо: **АИ-95**;
- страница сети: <https://gdebenz.ru/brand/rosneft>;
- страница АИ-95: <https://gdebenz.ru/fuel/ai-95>.

В Android-сборке форка карточка топливной точки маршрута показывает кнопку **«Проверить Роснефть АИ-95 на ГдеБЕНЗ»**. Она открывает страницу Роснефти в системном браузере; на сайте нужно включить фильтр **95** и проверить свежесть отметки перед заездом.

Интеграция намеренно browser-only: CoMaps не парсит, не скрейпит, не кэширует и не зеркалирует статусы ГдеБЕНЗ. Это сохраняет данные у их источника и не создаёт автоматизированный доступ к базе сервиса.

GPX дополнительно содержит стандартные `<link>` на страницы ГдеБЕНЗ у каждой из трёх топливных точек.

Важно: отметки ГдеБЕНЗ краудсорсинговые и могут меняться в пути. GPX хранит план остановок, а не подтверждение фактического наличия топлива.
